# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | ✅ Current          |

## Reporting a Vulnerability

If you discover a security vulnerability in Mise, please report it responsibly.

**Do NOT open a public GitHub issue for security vulnerabilities.**

Instead, please email: **security@mise.dev** (or reach out via GitHub private vulnerability reporting).

### What to include

- Description of the vulnerability
- Steps to reproduce
- Affected component(s) and version(s)
- Impact assessment (if possible)

### Response timeline

- **Acknowledgment**: within 48 hours
- **Initial assessment**: within 1 week
- **Fix timeline**: depends on severity, typically 1–4 weeks

We will credit reporters in release notes unless they prefer to remain anonymous.
